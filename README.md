## 🔄 How to Integrate Our Subscriptions

Instead of copying individual raw keys that may face targeted regional blocking, adding our master sync lines ensures your device auto-updates with healthy backup server IPs.

### 🤖 Quick Setup for v2rayNG (Android)
1. Navigate to our `subscriptions/` folder, select your preferred protocol (e.g., `vless.txt`), and click the **Raw** button.
2. **Copy the complete URL** from your browser address bar.
3. Open **v2rayNG** ➔ Tap the left side **Menu** ➔ Select **Subscription setting**.
4. Tap the **"+" icon** at the top right ➔ Input `Hosseinzadeh Net` as the remarks ➔ Paste your copied URL into the **URL** box ➔ Save.
5. Return to the app home screen ➔ Tap the **3 dots** (top right) ➔ Select **“Update subscription”**.

### 💻 Quick Setup for NekoBox (Windows/PC)
1. Capture the raw subscription text URL using the method described above.
2. Open **NekoBox** ➔ Select the **Groups** tab ➔ Click **New Group**.
3. Set Group Name to `Hosseinzadeh Net` ➔ Change Group Type to **Subscription**.
4. Paste the URL into the designated field ➔ Click **OK**.
5. Right-click your newly formed group and trigger **Update Subscription** to pull down active nodes.
